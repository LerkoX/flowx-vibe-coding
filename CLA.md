# 贡献者许可协议（CLA）

**版本 1.0 ｜ 生效日期：2026-10-13**

本协议适用于任何向 **LerkoX**（以下称「项目方」）拥有或维护的 FlowX 系列项目
（包括但不限于 `flowx`、`flowx-pixelforge`、`flowx-studio`、`flowx-vibe-coding`，
以下合称「本项目」）提交贡献的自然人或法人（以下称「贡献者」）。

签署本协议**不需要转让你的著作权**，你仍然拥有你贡献内容的版权。本协议只是
授予项目方一项足够宽泛的许可，使项目方能够持续维护本项目。

---

## 1. 定义

- **「贡献」**：指贡献者以任何形式（源代码、文档、设计、测试、配置、
  issue 中给出的补丁建议等）向本项目提交的、有意纳入本项目的任何原创作品。
- **「提交」**：指通过 Git 提交、Pull Request、邮件、issue 或其他任何渠道
  向本项目传递贡献的行为。
- **「项目方」**：指 LerkoX 及其明确指定的本项目著作权继受人。

## 2. 版权许可授予

贡献者保留其贡献的著作权所有权。**本协议不构成著作权转让。**

贡献者在此授予项目方一项**永久的、全球范围的、非排他的、免费的、不可撤销的、
可转让的**著作权许可，允许项目方：

1. 复制、修改、演绎、公开展示、公开传播、分发贡献及其衍生作品；
2. 将贡献及其衍生作品**再许可（sublicense）**给任何第三方；
3. 以**任何许可证条款**——包括但不限于 GPL-3.0-or-later 等开源许可证，
   以及完全专有的商业许可证——对贡献及其衍生作品进行**再授权（relicense）**
   与分发。

> **本条是本协议的核心条款。** 项目方以「开源 + 商业」双许可模式运营本项目：
> 社区可以按 GPL-3.0-or-later 自由使用，同时项目方向无法接受 GPL 开源义务的
> 客户提供商业许可。若无本条授予的再授权权利，项目方将无法继续提供商业许可。
> 贡献者在提交前应确认接受这一点。

## 3. 专利许可授予

贡献者在此授予项目方及其下游使用者一项永久的、全球范围的、非排他的、免费的、
不可撤销的专利许可，允许其制造、使用、销售、许诺销售、进口及以其他方式转让
贡献内容，但仅限于贡献者拥有的、且被其贡献单独或与贡献所纳入的本项目作品
结合而必然侵犯的专利权利要求。

若贡献者就本项目或本项目所含贡献，对项目方或任何下游使用者提起专利侵权诉讼
（包括诉讼中的反诉），则本协议第 2、3 条授予该贡献者的许可自起诉之日起终止。

## 4. 陈述与保证

贡献者向项目方陈述并保证：

1. 贡献者系贡献的著作权人，或已获得著作权人的充分授权，有权按本协议条款
   授予上述许可；
2. 贡献为原创作品，或贡献者已明确标注其中来自第三方的部分及其许可证；
3. 据贡献者所知，贡献不侵犯任何第三方的著作权、专利权、商标权或商业秘密；
4. 贡献者已遵守其雇主或任何第三方就贡献所施加的、与本协议不冲突的义务。

## 5. 职务作品与雇主授权

若贡献系贡献者在受雇期间、为雇主业务之目的作出，或依适用法律构成**职务作品**，
贡献者应确保已获得雇主按本协议条款进行许可的必要授权，或由雇主另行签署本协议
（见 `CLA-Corporate.md`）。

**贡献者不得在未获雇主授权的情况下提交职务作品。**

## 6. 无担保

贡献按「现状」提供，不附带任何形式的明示或默示担保，包括但不限于对适销性、
特定用途适用性及不侵权的担保。在任何情况下，贡献者均不对因贡献或本协议
产生的任何索赔、损害或其他责任承担责任。

## 7. 无义务使用

本协议不要求项目方必须使用、合并或分发贡献者的任何贡献。项目方保留自行决定
是否接受贡献，以及是否在未来移除贡献的权利。

## 8. 记录与签署

以任何方式签署本协议，即视为接受本协议全部条款，包括但不限于：

- 通过 CLA Assistant 等工具在 Pull Request 中进行的电子签署；
- 在提交信息中附加 `Signed-off-by: 姓名 <邮箱>` 行；
- 书面签署并将扫描件发送至项目方。

贡献者的提交记录、Pull Request 中的签署记录，构成本协议签署的有效证明。

## 9. 协议修订

项目方可能在未来修订本协议。修订仅适用于修订生效**之后**提交的贡献；
修订生效前已提交的贡献，仍适用其提交时有效的版本。修订后的协议将发布在
本仓库 `CLA.md`，并标注新的版本号与生效日期。

## 10. 适用法律与争议解决

本协议适用中华人民共和国法律。因本协议产生的争议，双方应首先友好协商解决；
协商不成的，提交项目方所在地有管辖权的人民法院诉讼解决。

## 11. 完整协议

本协议构成双方就贡献许可事项的完整约定，取代此前任何口头或书面的相关沟通。
本协议任一条款被认定无效或不可执行的，不影响其余条款的效力。
